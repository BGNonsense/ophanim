Welcome, player.

FOR THE BEST EXPERIENCE, SET THE MENU TO HORIZONTAL SCROLLING, COLUMNS TO 7, AND ITEM SPACING TO 135!

Before you jump into Ophanim, just know that the theme is intended to be full of style, emulating the feel of old-school game consoles like the original Xbox and the PS2. It's still just as functional as the default fullscreen Playnite theme, so don't worry about its function being sacrificed as a result. It is a LARGE theme because the background is a 4K video playing on a loop.

Ophanim supports the "NowPlaying" extension by JonoSellier, too. In order for the text to appear properly, please install the "OCR A Extended" TrueType font. I bundled it with the "fonts" folder.

Thanks, and remember... be not bored.
