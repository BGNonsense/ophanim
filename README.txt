Welcome to Ophanim!

Before you jump into Ophanim, just know that the theme is intended to be full of style, emulating the feel of old-school game consoles like the original Xbox and the PS2.

It's still just as functional as the default fullscreen Playnite theme, so don't worry about its function being sacrificed as a result.

It supports the "NowPlaying" extension, too. In order for the text to appear properly, please install the "OCR A Extended" TrueType font. I bundled it with the "fonts" folder.

Will recommend that if you intend on keeping it, enter the Ophanim folder, go to scripts, and ensure that you set the batch 
file as a shell:startup command, or set the OphanimIntro in the Videos folder to the BootVid extension.

Thanks, and remember... be not bored.
